# Tapab Bin

Console application project for DSA based on a drink vending machine named Tapab Bin.

## DSA concepts used

- `Queue`: stores customer orders waiting to be prepared.
- `Singly Linked List`: stores the drink menu.
- `Stack`: stores completed order history and shows the latest completed order.
- `Iterative`: used in the main menu, queue traversal, and ID search.
- `Recursive`: used for drink name search and recursive menu display.

## Main features

- Show drink menu
- Search drink by name
- Place an order
- Show waiting queue
- Add drink
- Remove drink
- Process next order
- Show last completed order
- Show sales summary

## Run

### Java

```bash
javac TapabBin.java
java TapabBin
```
